Data engineeringOnline Retail ETL and Business Intelligence+

An end-to-end ETL pipeline that turns raw retail transactions into a star-schema data warehouse and an interactive Power BI dashboard. Python handles preprocessing (duplicates, missing values, invalid quantities and prices), Pentaho Data Integration runs four transformations (dim_product, dim_customer, dim_time, fact_sales) orchestrated by one job, and MySQL stores the staging and warehouse tables.

The dashboard shows that the UK accounts for over 92% of transactions, sales peak in October and November, and returning customers outnumber new ones every month.

Big dataHome Credit Default Risk+

A group case study on predicting loan default risk. Kaggle data was stored in HDFS (Cloudera Quickstart VM) and processed with PySpark: cleaning, validation, aggregation, and feature engineering such as credit-to-income ratios and credit history features. A Random Forest classifier predicts likely defaulters.

External credit scores, employment duration, and age were the strongest predictors. Limitations include class imbalance and running Spark in local mode instead of on a physical cluster.

Machine learningJoin Order Optimization+

A lightweight framework that predicts query cost and picks a better join order for hash join queries using only structural query features. Built on 720 query executions from the Classicmodels MySQL database with 17 features. Linear Regression on log-transformed execution time estimates cost, and a Greedy Algorithm selects the lowest predicted-cost order.

The greedy order ran faster in 60.2% of scenarios, averaging a 2.87% speedup and reaching 39.62% at best. Five-table joins gained the most (9.21% on average).
